ตรวจข้อมูลเพิ่มเติมของผู้กู้

ตรวจเอกสาร ข้อมูลส่วนบุคคล รายได้ ภาระหนี้ บัญชีรับเงิน และประวัติการแก้ไข หลังอนุมัติคำขอเบื้องต้น

ตรวจสอบข้อมูลกับหลักฐานจริงก่อนตัดสินใจ เอกสารที่ส่งเพิ่มไม่ได้รับประกันการอนุมัติ และการอนุมัติข้อมูลเพิ่มเติมยังไม่ใช่การโอนเงินจริง
— รายการ

ผลิตภัณฑ์สินเชื่อ

กำหนดวงเงิน ระยะเวลาผ่อน วิธีคำนวณ และรอบชำระที่รองรับ

การเปิดใช้ผลิตภัณฑ์ต้องผ่านการตรวจสอบเงื่อนไขและข้อกำกับก่อน หากแก้ดอกเบี้ยหรือค่าธรรมเนียม ควรตรวจทานผลกระทบต่อข้อเสนอและสัญญาที่มีอยู่ก่อนเผยแพร่

รายการชำระเงิน

ติดตาม QR รายการชำระ และสถานะตรวจสอบสลิป

API ปัจจุบันไม่ได้ส่ง URL หรือไฟล์สลิปกลับมาให้หน้า Admin จึงแสดงได้เฉพาะข้อมูลธุรกรรม และสถานะจากผู้ให้บริการ การปฏิเสธหรือส่งตรวจใหม่จะไม่ยืนยันว่าเงินถูกคืนหรือโอนแล้ว
— รายการ

จัดการประกาศ

เพิ่มข่าวสาร เลือกตำแหน่งแสดงผล อัปโหลดรูปภาพ และพรีวิว HTML ก่อนบันทึก

รูปประกาศแนะนำขนาด 1200 × 500 พิกเซล หรืออัตราส่วนประมาณ 12:5 เพื่อให้เหมาะกับแบนเนอร์หน้าเว็บ รองรับ JPG, PNG และ WebP โดยขนาดไฟล์ไม่เกิน 4 MiB ใช้ ImgBB สำหรับภาพที่ตั้งใจเผยแพร่ต่อสาธารณะเท่านั้น ห้ามอัปโหลดบัตรประชาชนหรือสลิปชำระเงิน

ปิดระบบชั่วคราว

ตั้งเวลาปิด–เปิดระบบอัตโนมัติ พร้อมรูปภาพและเนื้อหา HTML ที่จะแสดงแทนหน้า Login

กำลังโหลดสถานะการปิดระบบ

เมื่อเปิดใช้ ระบบจะแสดงหน้าปิดปรับปรุงระหว่างเวลาเริ่มต้นกับเวลาสิ้นสุด หากไม่ระบุเวลาเริ่ม ระบบจะปิดทันที และหากไม่ระบุเวลาสิ้นสุด ระบบจะปิดต่อไปจนกว่าจะปิดตัวเลือกนี้
